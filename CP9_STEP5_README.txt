PROJECT 12 — CP9 / STEP 5: OFFLINE TERRAFORM FOUNDATION

WHAT THIS PACKAGE DOES
- Replaces infrastructure/terraform/main.tf, variables.tf, outputs.tf.
- Updates root .gitignore and .dockerignore while preserving CP8 secret protections.
- Defines immutable, scanned Amazon ECR repository, ECS cluster, CloudWatch log group
  and ECR cleanup policy, ALL gated behind enable_aws_resources (default false).
- Does not configure VPC, task definition, ECS service, ALB, IAM execution roles,
  S3 model transport or AWS Secrets Manager yet. These need design/approval first.
- Does not enable model serving: your model loader correctly rejects non-local
  serving of unpromoted models, and Docker currently uses a LOCAL host-mounted bundle.

INSTALLATION
1. Back up current Terraform files and root .gitignore/.dockerignore if desired.
2. Extract this ZIP at the Project 12 repository ROOT, preserving folder paths.
   Replace matching files. Do not replace or reveal .env or .secrets contents.
3. Keep the existing infrastructure/terraform/.terraform.lock.hcl generated by your
   successful Terraform init; it pins AWS provider 5.100.0.
4. In PowerShell, from the project root, run:

   terraform -chdir=".\infrastructure\terraform" fmt -check -diff
   terraform -chdir=".\infrastructure\terraform" init -backend=false -input=false
   terraform -chdir=".\infrastructure\terraform" validate
   git check-ignore .secrets/api_key.txt
   git check-ignore infrastructure/terraform/.terraform/providers
   git check-ignore infrastructure/terraform/terraform.tfstate
   git check-ignore infrastructure/terraform/.terraform.lock.hcl

   The FINAL git check-ignore command SHOULD produce NO matching result: the lockfile
   is intended to be committed. Other three paths should be ignored.

5. Show the Terraform fmt/init/validate output. DO NOT run terraform plan or apply.

COST AND SAFETY
- enable_aws_resources defaults to false; nothing is provisioned here.
- terraform init contacts the public Terraform provider registry, not your AWS account.
- ECR storage, logs, service runtimes, ALB, public IPv4 or endpoints may cost money
  if deployed later. Costs and network exposure will be reviewed separately.
- Local synthetic-data model remains candidate_not_promoted; no cloud deployment.
- A raw joblib/pickle model must not be treated as trusted without checksum and provenance.
